Slide 3 (code):
Dark slide titled 'Why Quality Never Drops: Modified Rejection Sampling'. A syntax-highlighted Python code block shows a rejection-sampling loop: for each draft token, compute an acceptance probability as the minimum of 1.0 and the ratio of the target model's probability to the draft model's probability for that token; if a random draw is below that threshold, accept the token and advance; otherwise reject it, build a residual distribution by clipping the target probabilities minus the draft probabilities to zero and normalizing, then sample the corrected token from that residual and stop the round. A trailing comment block notes that if every draft token is accepted, the target model already scored one extra position for free in the same pass, so that bonus token is sampled directly.
